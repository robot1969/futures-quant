# 🦞 期货量化模拟盘系统

> 全品种 · 全周期 · 全指标 · 全策略 · 本地公平数据

---

## 📋 项目概述

这是一个**完全本地化**的期货量化交易模拟系统，所有数据均采用**公平随机生成**，确保每个合约在相同条件下竞争。

### 核心特性

- ✅ **全品种覆盖**: 53 个期货合约
- ✅ **全周期支持**: 10 个时间周期（1 分钟~月线）
- ✅ **全指标计算**: 203 个技术指标
- ✅ **全策略库**: 232 个交易策略
- ✅ **公平数据**: 本地随机生成，无偏差
- ✅ **风险管理**: 止损/止盈/仓位控制

## 🎯 公平数据生成机制

### 核心原则

1. **统一起点**: 所有合约从相同基准价格（5000）开始
2. **随机方向**: 50% 上涨概率，50% 下跌概率
3. **统一波动**: 所有合约使用相同波动率范围（1%-2.5%）
4. **可重复性**: 相同合约代码产生相同数据序列
5. **独立随机**: 每个合约使用独立的随机种子

### 数据生成公式

```
价格 = 基准价 + 趋势 + 周期 + 随机游走

其中：
- 趋势 = 累积随机游走 × 方向因子
- 周期 = 正弦波（模拟市场周期）
- 随机游走 = 正态分布随机数 × 波动率
```

## 📈 绩效评估指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| **总收益率** | 总体盈利比例 | (期末资金 - 期初资金) / 期初资金 |
| **夏普比率** | 风险调整后收益 | (收益率 - 无风险利率) / 波动率 |
| **最大回撤** | 最大亏损幅度 | 最大连续亏损比例 |
| **胜率** | 盈利交易比例 | 盈利次数 / 总交易次数 |
| **盈亏比** | 平均盈亏比 | 平均盈利 / 平均亏损 |
| **波动率** | 收益波动程度 | 收益率的标准差 |

## ⚠️ 风险提示

1. **模拟盘性质**: 本系统为模拟交易系统，不构成投资建议
2. **数据公平性**: 使用随机生成数据，与真实市场存在差异
3. **策略风险**: 历史表现不代表未来收益
4. **资金管理**: 请合理控制仓位，避免过度交易
